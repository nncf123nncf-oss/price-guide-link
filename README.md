# 料金の目安リンクメーカー（price-guide-link）

メニューとオプションの金額を入れてリンクを1本作ると、お客さんがそのリンクで条件を選んで、合計の目安を見られる1ページの道具です。

- 設定はURLの `#` 以降に入ります。サーバー・アカウントは使いません
- お客さんが選んだ内容は、事業者には送られません。お客さんが相談文をコピーして、いつもの連絡手段に貼ります
- 作る側の下書きだけ、お使いの端末のブラウザ（localStorage）に保存します。リンクそのものは保存しないので、URLを控えてください
- リンク（http・www など）は入力できません。表示は目安で、正式な金額は事業者が伝えます

- `node source/core-test.js` 金額・端数・URLの往復・壊れたリンク・入力の境界の検算
